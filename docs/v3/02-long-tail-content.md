# v3 Long-Tail Content

Systems that give players reasons to return **after** the core bucket loop feels good. Economy gates must align with [findings/economy-progression-findings.md](findings/economy-progression-findings.md) — if curves are too fast, crew and milestones arrive too early.

## Crew (Rat friends)

Supersedes v1 "golf friend." See [v2/05-characters-and-crew.md](../v2/05-characters-and-crew.md).

| Phase | Content |
|-------|---------|
| v3.0 | First rat friend bay — passive swings, mediocre timing |
| v3.1 | Crew upgrades (cadence, payout mult) |
| v3.2 | Second bay, combo synergy (+25% when player combo active) |

**Unlock gate (target):** $250k lifetime earnings (~session 2 with tuned curves).

**Design rule:** Passive ≈ 15% of active pickup at hire; scale slowly (1.08–1.12× upgrades).

## Range amenities (passive_range)

Deferred shop layer — visible diorama improvements:

- Crack patch, grass tiers, scarecrow (gopher counter)
- Lights, sign, vending — small passive `$` or pickup bonus
- Tied to **lifetime milestones**, not only upgrade tree

## Zones

Same 3D scene first; unlock later:

- Target bay (bullseye mult)
- Night range (atmosphere + set bonus)

Out of scope until economy pass is stable.

## Milestones (UI)

Always show next goal, e.g.:

> Next: Hire a rat friend at $250,000 lifetime ($48,200 to go)

Examples from v1/v2 docs, retuned for v3 pacing:

| Milestone | Unlocks |
|-----------|---------|
| $250 | First "big number" beat |
| $10k | Atmosphere / QoL candidate |
| $250k | First crew hire |
| $2M | Second crew slot |
| $50k lifetime yards | Target bay (future) |

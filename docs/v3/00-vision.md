# v3 Vision

## Elevator pitch

The range **works** — bucket, contact, pickup, upgrades. v3 makes it **last**: slower exponential curves, branch choices that matter for an hour, crew on the sideline, and a range that visibly improves as you play.

## Creative north star

**Same soul as v2. Longer runway. Clearer stakes.**

| Pillar | v3 meaning |
|--------|------------|
| **One more bucket** | Upgrades should cost **1–3 buckets** early, **3–8** mid — not always exactly one. |
| **Skill stays relevant** | Economy amplifies Perfect hits and harvest combos; it does not replace them. |
| **Branch identity** | Power = distance spectacle; Quality = contact skill; Pickup = harvest flow; Base Pay = spine. |
| **Superintendent payoff** | Crew and range upgrades change what you **see**, not only HUD numbers. |
| **Calm default** | Still Ghibli-adjacent — no casino pacing to fake engagement. |

## What v3 is

- Economy rebalance (per-branch exponential rates)
- Milestone and crew gates tuned to **multi-session** play
- Long-tail content: rat friends, range amenities, optional zones
- Balance tooling and verify scripts aligned to payback targets

## What v3 is not

- Replacing contact swing with hold-to-charge
- Prestige / reset (unless explicitly scoped later)
- Purple casino UI or loot-box pacing
- Deleting v1/v2 doc history

## Player journey (target)

| Session | Feel |
|---------|------|
| **First 15 min** | Learn contact, unlock tree, pick first branch, numbers move |
| **30–60 min** | Stack 2–3 branches, combo harvest, see fairway depth grow |
| **Session 2+** | Afford crew, range looks busier, passive supplements active play |
| **Long tail** | Deep tree, new zones, jackpot spikes still rare and earned |

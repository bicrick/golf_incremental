# v7 UI — Upgrade Menu Prestige Tab

## Upgrade menu structure

The upgrade overlay gains **two tabs**:

| Tab | Currency shown (top-right of panel) | Content |
|-----|-------------------------------------|---------|
| **Base** | **Cash $** | Existing cash skill tree (trimmed per [03-base-tree-and-pace.md](03-base-tree-and-pace.md)) |
| **Prestige** | **Cheese** | Cheese skill tree + prestige affordance + prestige # |

Switching tabs swaps the visible graph and the header currency. Do **not** show cash as the primary header currency on the Prestige tab. Prestige tab is always browsable (even under $500).

## Prestige celebration ritual (three beats)

After confirming cash-out, gameplay leaves the normal upgrade panel and enters [`PrestigeFlow`](../../scenes/ui/prestige_flow.tscn):

1. **Celebrate** — Fullscreen sky + “PRESTIGE!” + `+N cheese`. **One cheese sprite per cheese earned** (no cap) flies into a slot-reel counter (previous total → new total). Fanfare + throttled plinks. **Advance** continues.
2. **Shop** — Prestige-only upgrade tree (`open_ritual_shop`): no Base tab, no Back, no cash-out button. Cheese balance live. Second **Advance** continues.
3. **Return** — Close ritual + panel; `RangeView.prepare_after_prestige()` forces strike phase, clears litter/flights; player hits again on a wiped Play run.

State: `GameState.prestige()` runs once at ritual start (wipe + grant cheese). Celebrate only animates display.

## Prestige tab chrome (normal menu)

| Element | Placement | Behavior |
|---------|-----------|----------|
| **Cheese balance** | Top-right of prestige panel | Live updates |
| **Prestige #** | Top bar | `Prestige #<prestige_count>` |
| **Prestige button** | Bottom-right | Cash-out only; confirm → celebration ritual |

### Prestige button states

| State | Look | Interaction |
|-------|------|-------------|
| `cash < prestige_threshold` | Greyed out | Styled tooltip: need $X on hand |
| `cash >= prestige_threshold` | Enabled | Confirm → PrestigeFlow ritual |

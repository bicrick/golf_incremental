# v7 UI — Upgrade Menu Prestige Tab

## Upgrade menu structure

The upgrade overlay gains **two tabs** (names flexible):

| Tab | Currency shown (top-right of panel) | Content |
|-----|-------------------------------------|---------|
| **Play** (or Upgrades) | **Cash $** | Existing cash skill tree (trimmed per [03-base-tree-and-pace.md](03-base-tree-and-pace.md)) |
| **Prestige** | **Cheese** | Cheese skill tree + prestige affordance + prestige # |

Switching tabs swaps the visible graph and the header currency. Do **not** show cash as the primary header currency on the Prestige tab.

## Prestige tab chrome

| Element | Placement | Behavior |
|---------|-----------|----------|
| **Cheese balance** | Top-right of prestige panel (where $ usually is) | Live updates on cheese change |
| **Prestige #** | Top bar of prestige panel | `Prestige #<prestige_count>` (0 before first prestige is fine) |
| **Prestige button** | Bottom-right of prestige panel (small) | Primary CTA to prestige |

### Prestige button states

| State | Look | Interaction |
|-------|------|-------------|
| `cash < prestige_threshold` | Greyed out | Tooltip: requires `$X` on hand (show threshold and/or shortfall). Short description of prestige (reset Play progress, gain cheese). |
| `cash >= prestige_threshold` | Enabled / highlighted | Click → confirm → run prestige flow ([01-prestige-loop.md](01-prestige-loop.md)) |

Not a node on the Play tree. Lives only on the Prestige tab UI.

## Play tab

- Unchanged chrome aside from removals (no Ratina/Rattling/combo/quick_reset nodes).
- Top-right remains **cash**.

## HUD (main range)

- No requirement to show cheese on the main HUD for v7 (Prestige tab is enough). Optional later: small cheese icon if playtests demand it.
- Prestige readiness indicator on main HUD is **optional**; Prestige tab button is required.

## Copy (starting point)

**Button label:** `Prestige`

**Disabled tooltip:**  
`Need $5,000 on hand to prestige.` (use live threshold)  
`Reset cash upgrades and cash. Keep cheese and prestige perks.`

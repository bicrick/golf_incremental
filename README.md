## Stack

| | |
|---|---|
| Engine | [Godot](https://godotengine.org/) 4 + GDScript |
| Art | [PixelLab](https://pixellab.ai/) |
| Editor | [Cursor](https://cursor.com/) |
| Hosting | [Vercel](https://vercel.com/) |

## Run locally

1. Open the project in **Godot 4**
2. Press **F5**

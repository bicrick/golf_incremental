# Range Rat

A short pixel-art golf incremental. **Range Rat has hit a million balls and never once played a hole.** Follow Ratina's pink flags across five ranges — a dawn meadow, sea cliffs, a desert mesa, a snowy night, and the edge of the world — to play the Longest Hole at sunrise. About 25 minutes, with a real ending.

## Stack

| | |
|---|---|
| Engine | [Godot](https://godotengine.org/) 4 + GDScript |
| Art | [PixelLab](https://pixellab.ai/) characters + procedural pixel art (`tools/art/`) |
| Editor | [Cursor](https://cursor.com/) |
| Hosting | [Vercel](https://vercel.com/) |

---

## Run locally

1. Open the project in **Godot 4**
2. Press **F5**

Design notes live in [`docs/v8/`](docs/v8/README.md).

## Controls

| | |
|---|---|
| Swing | Hold **Space** or the mouse, let go when the ring closes on the ball |
| Aim | **A / D** (or click a flag) · **W / S** nudge distance |
| Shop | **Tab** |
| Journal / Map / Pause | **J** / **M** / **Esc** |
